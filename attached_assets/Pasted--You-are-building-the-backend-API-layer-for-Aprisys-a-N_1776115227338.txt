
You are building the backend API layer for **Aprisys**, a Nigerian capital markets platform. This backend is called **Cellion One API**. It will be consumed by two React frontends: CIE Digest (retail intelligence portal) and CDI (professional deal execution portal).

---

## STACK
- Runtime: Node.js with Express
- Language: JavaScript (CommonJS)
- Database: Replit's built-in PostgreSQL (use the DATABASE_URL environment variable)
- ORM: Drizzle ORM
- Auth: JWT (jsonwebtoken + bcryptjs)
- CORS: enabled for frontend origins

## DATABASE SCHEMA (define in /src/db/schema.js using Drizzle)

Create the following tables:

### users
- id (uuid, primary key, default gen_random_uuid())
- email (text, unique, not null)
- password_hash (text, not null)
- full_name (text)
- role (text, default 'retail') — values: 'retail', 'professional', 'admin'
- created_at (timestamp, default now())

### securities
- id (uuid, primary key)
- ticker (text, unique, not null)
- name (text, not null)
- sector (text)
- exchange (text, default 'NGX')
- market_cap (numeric)
- updated_at (timestamp)

### prices
- id (uuid, primary key)
- security_id (uuid, foreign key → securities.id)
- close_price (numeric, not null)
- open_price (numeric)
- high (numeric)
- low (numeric)
- volume (bigint)
- trade_date (date, not null)

### companies
- id (uuid, primary key)
- security_id (uuid, foreign key → securities.id)
- description (text)
- ceo (text)
- founded_year (integer)
- website (text)
- employees (integer)

### news_articles
- id (uuid, primary key)
- title (text, not null)
- summary (text)
- source (text)
- url (text)
- category (text) — e.g. 'equities', 'bonds', 'macro', 'deals'
- published_at (timestamp)
- created_at (timestamp, default now())

### watchlists
- id (uuid, primary key)
- user_id (uuid, foreign key → users.id)
- security_id (uuid, foreign key → securities.id)
- added_at (timestamp, default now())

### portfolio_holdings
- id (uuid, primary key)
- user_id (uuid, foreign key → users.id)
- security_id (uuid, foreign key → securities.id)
- quantity (numeric, not null)
- avg_buy_price (numeric)
- created_at (timestamp, default now())

### deals (CDI)
- id (uuid, primary key)
- title (text, not null)
- deal_type (text) — e.g. 'IPO', 'rights_issue', 'bond', 'private_placement'
- issuer (text)
- status (text, default 'open') — 'open', 'closed', 'pending'
- value_ngn (numeric)
- open_date (date)
- close_date (date)
- description (text)
- created_at (timestamp, default now())

## API ROUTES TO IMPLEMENT

### POST /api/user/register
- Accepts: { email, password, full_name, role }
- Hashes password with bcryptjs
- Saves user to DB
- Returns: { message: 'User registered', userId }

### POST /api/user/login
- Accepts: { email, password }
- Validates credentials
- Returns: { token, user: { id, email, full_name, role } }

### GET /api/user/me  ← protected
- Returns current user profile from JWT

### GET /api/user/watchlist  ← protected
- Returns user's watchlisted securities with latest price

### POST /api/user/watchlist  ← protected
- Body: { security_id }
- Adds security to user's watchlist

### DELETE /api/user/watchlist/:security_id  ← protected
- Removes from watchlist

### GET /api/market-data/securities
- Query params: ?sector=&exchange=&search=
- Returns paginated list of securities with latest price

### GET /api/market-data/securities/:ticker
- Returns single security with latest price and 30-day price history

### GET /api/market-data/indices
- Returns hardcoded or seeded NGX All-Share Index, NGX 30, NGX Pension mock data for now

### GET /api/companies
- Query params: ?sector=&search=
- Returns list of companies joined with securities

### GET /api/companies/:ticker
- Returns full company profile with security data

### GET /api/news
- Query params: ?category=&limit=20&offset=0
- Returns news articles ordered by published_at DESC

### GET /api/news/:id
- Returns single article

### GET /api/portfolio  ← protected
- Returns user's holdings with current value and P&L calculation

### POST /api/portfolio  ← protected
- Body: { security_id, quantity, avg_buy_price }
- Adds or updates holding

### GET /api/deals  ← protected (role: professional or admin)
- Returns all deals ordered by open_date DESC

### GET /api/deals/:id  ← protected (role: professional or admin)
- Returns single deal

### POST /api/deals  ← protected (role: admin only)
- Creates a new deal

## AUTH MIDDLEWARE

Create /src/middleware/auth.js:
- Reads Bearer token from Authorization header
- Verifies JWT using JWT_SECRET
- Attaches decoded user to req.user
- Returns 401 if missing or invalid

Create a role check helper:
- requireRole(...roles) — returns middleware that checks req.user.role
