Bank partner integration is a future phase — the architecture should make it easy to swap the subaccount details later without code changes.
2. DVA bank: Default to Titan-Paystack (9101 prefix) as the primary DVA provider because it supports Inbound Transfer Approval. Support Wema Bank (0121 prefix) as fallback. At DVA creation time, try Titan first, fall back to Wema if unavailable.
3. Beneficiary details timing: Collect seller/beneficiary bank details at escrow initialisation time, not at release. At initialisation, validate the account name via Paystack's account resolution API (GET /bank/resolve?account_number=&bank_code=) and store the validated name, account number, and bank code against the escrow record. Reject initialisation if account resolution fails — this prevents wrong transfers. At release time, use the stored validated details to create a Paystack transfer recipient and initiate the transfer immediately.
