You are a senior full-stack engineer extending the existing Celine One (Cellion One) codebase.

GOAL
Implement Paystack split checkout for Nigeria (NGN) using a fixed-cut product catalog where:
- Each product has a fixed NGN price
- Cellion keeps a fixed NGN “cut”
- The remaining amount is settled to the Lawyer via Paystack Subaccount
- Payments are tied to either:
  a) an incorporation application (applicationId), or
  b) a standalone service purchase (e.g., SCUML, Trademark, Registered Office when Paystack is used later)

Use Paystack Subaccounts + transaction_charge (fixed split) and verify via webhooks.

CRITICAL REQUIREMENTS
1) NEVER trust client-provided prices/cuts. Server must compute from ProductCatalog by SKU.
2) For every payment, record the split breakdown in DB: total, cellion_cut, lawyer_net.
3) All Paystack webhooks must be verified with Paystack signature.
4) Only mark orders paid after webhook verification (not on redirect).
5) Feature flags must allow turning Paystack on/off cleanly without breaking existing flows.

PART 3 — BACKEND SERVICES (Express)
========================================================

A) productCatalogService
- getActiveProducts()
- getBySku(sku)
- computeItemAmounts(sku):
  - fetch product
  - if requires_manual_pricing => throw error "MANUAL_PRICING_REQUIRED"
  - return { price_ngn, cellion_cut_ngn, lawyer_net_ngn }

B) orderService
- createOrder(founderId, applicationId?, items:[{sku}]):
  - validate each sku exists and active
  - compute totals server-side
  - create Order + OrderItems with split breakdown
  - status = pending_payment
  - return order

C) paystackService
- initializeTransaction({order, founderEmail}):
  - amount = order.total_amount (in kobo? Paystack uses kobo; multiply by 100 if required)
  - currency NGN
  - callback_url PAYSTACK_CALLBACK_URL + ?orderId=...
  - metadata include:
      - orderId
      - founderId
      - applicationId
      - items (sku list)
  - SPLIT:
      - subaccount = PAYSTACK_LAWYER_SUBACCOUNT_CODE
      - transaction_charge = TOTAL_CELLION_CUT (sum of item cuts)
    NOTE: If Paystack requires transaction_charge in kobo, multiply by 100.
  - Return authorization_url + reference

- verifyWebhookSignature(req):
  - validate Paystack signature header per official docs; reject if invalid

- handleWebhook(event):
  - on charge.success:
      - find Payment by reference
      - verify amounts match expected (server-side)
      - mark Payment paid; store raw_event; paid_at
      - mark Order paid
      - trigger business activations:
          * if applicationId exists:
              - mark incorporation payment step complete OR set application paymentStatus=paid
          * if items include SCUML/TM/TIN:
              - create service requests / tasks for lawyer/admin queue
      - write audit log entries:
          - payment_initiated
          - payment_succeeded
          - order_paid
          - payout_split_recorded
  - on charge.failed:
      - mark Payment failed; Order failed; audit log

- Founder authenticated; must own order
- Ensure order status pending_payment
- Create Payment record status=initiated

- Return { authorization_url, reference }

D) Webhook
POST /api/payments/paystack/webhook
- No auth
- Verify signature
- Process event
- Return 200 quickly

E) Payment status
GET /api/orders/:orderId
- Founder authenticated; ownership check
- Return order + items + payment status
