# Cellion One - Nigeria Legal Tech Platform

## Overview
Cellion One is a comprehensive legal tech platform designed to streamline company incorporation and related legal services in Nigeria. It aims to revolutionize legal processes for Founders, Lawyers, and Administrators by offering an efficient, transparent, and technology-driven solution, thereby simplifying a complex legal process and setting new standards for legal tech in Nigeria. Key capabilities include a digital application wizard, document management, integrated payments, AI-powered suggestions, lawyer assignment, and robust administrative controls.

## System Architecture
The platform utilizes a modern web stack: React with TypeScript, Vite, Tailwind CSS, and shadcn/ui for the frontend; Express.js with TypeScript for the backend; and PostgreSQL (Neon-backed) for the database. Authentication uses a custom email/password system. The UI/UX features a primary green/teal color scheme (hsl(156 72% 35%)) and full dark mode support. It supports four distinct user roles: Founder, Lawyer, Admin, and Building Manager, each with tailored portals.

Key architectural decisions and features include:
-   **Modular Design:** Reusable frontend components and a structured backend with clear separation of concerns.
-   **Progressive Web Application (PWA):** Supports offline functionality.
-   **Payment System:** Paystack-only for NGN, supporting split payments and auto-settlement, with an optional banking partner fee layer.
-   **Registered Office Service:** Tiered virtual address services with mail handling and automated subscription management.
-   **Security & Administration:** Super admin controls, feature flags, comprehensive audit logging, 2FA via SMS OTP, sensitive data access logging, and a robust security hardening suite including HTTP headers, rate limiting, and CSRF protection.
-   **Post-Incorporation Support:** AI Legal Assistant, digital Company Profiles, a 10-task Post-Incorporation Checklist, and an auto-calculated Compliance Calendar with email reminders.
-   **Identity & KYC:** Comprehensive 4-step identity verification via Smile ID (BVN/NIN, document, biometric, AML/sanctions) for individuals, and a full KYC-as-a-Service module for individuals and corporates. This includes hosted verification sessions, a public API, verified identity profile store, AML monitoring hub, and STR Report Builder.
-   **Existing Company Verified Onboarding:** A 5-step wizard (`/founder/existing-company`) allowing existing Nigerian companies to register on Cellion One. **Verification is completely free** — no payment required from the founder. Step 1: CAC RC Lookup via Smile ID KYB (with company type mapper — maps PRIVATE_COMPANY_LIMITED_BY_SHARES → LTD etc. and slices ISO datetime to YYYY-MM-DD); Step 2: Company Detail Confirmation (fields locked/read-only when KYB succeeds, address pre-fills from split addressLine1/addressState/addressCountry fields); Step 3: Directors — supports both individual (BVN or NIN required) and corporate entities (RC Number required, KYB verification via CAC); Step 4: Vault Documents (all optional — messaging explains documents go to secure vault for bank/legal use, "Skip for now" option); Step 5: Submit Application (free — no payment, triggers pipeline immediately). Post-submission pipeline: KYB + TIN + director BVN/NIN/AML checks (individual) or KYB+AML checks (corporate) → auto-approve if all pass → `verified`; else → `under_review`. Status lifecycle: `draft → pending_review → verified | under_review | rejected`. Backend route: `POST /api/founder/company-profiles/:id/checkout` sets status to `pending_review` and calls `runExistingCompanyVerificationPipeline(profileId)` from `paystackWebhookHandler.ts`. Schema: `verificationReport` JSON column on `company_profiles`. Admin panel at `/admin/existing-companies` shows structured Verification Report with per-check pass/fail badges; `under_review` status filter added.
-   **Corporate Shareholders & Directors (Task #83):** Full support for corporate entities (companies, trusts) as directors/shareholders across all three entry points: (1) new incorporation wizard Step 4 — Individual/Corporate toggle, corporate form captures entity name, RC number, country, authorised rep name & email; (2) existing company wizard Step 3 — same toggle, corporate entries skip BVN/NIN requirement; (3) directors management page (`/founder/company-people`) — "Add" dialog has Individual/Corporate tabs, corporate entries display with Building2 icon and "Corporate" badge. Schema: 5 new columns on `company_people` table (`entityType`, `corporateName`, `corporateRcNumber`, `corporateCountry`, `corporateAuthorisedRepName`). Backend: `POST /api/company-people` handles both types; checkout route prices corporate entities at ₦15,000 each (`CORPORATE_KYB` SKU); webhook pipeline verifies corporate entities via Smile ID KYB on RC number + AML on authorised rep, issues biometric invite to the rep, and applies type-aware pass/fail logic.
-   **10% Administration Fee & Corrected Lawyer Splits (Task #84):** All standard checkout orders (incorporation, SCUML, Trademark, etc.) now include a 10% Administration Fee on top of the service subtotal. The fee is computed server-side in `/api/checkout/split`: `adminFeeAmount = round(subtotal × 0.10)`, stored in the `adminFeeAmount` column on the `orders` table (added via schema migration), and the total passed to Paystack = subtotal + adminFee. Frontend (`/founder/checkout`) shows Subtotal + Administration Fee (10%) + Total lines in the Order Summary. Application detail page (`/applications/[id]`) also shows the breakdown. Corrected lawyer `cellionCutNgn` splits in seed.ts: CAC_1M ₦25k, CAC_5M ₦30k, CAC_10M ₦35k, CAC_20M ₦40k, CAC_100M ₦100k, SCUML ₦25k, TM ₦35k.
-   **User Management:** Personal profile system with encrypted NIN/BVN storage, document uploads, and Director/Shareholder management with individual verification.
-   **Procurement Marketplace:** A full RFQ/Bid/Contract/Invoice system for verified organizations with escrow payments.
-   **Escrow-as-a-Service API:** Public REST API for third-party platforms to manage escrow transactions.
-   **CIE (Cellion Intelligence Engine):** A subscription API serving NGX equity intelligence with tiered access and integrated billing. Includes: Admin Cockpit (`/admin/cie`) with 7 tabs (Securities, Price Upload, Model Editor, Dividends, Signals, Partners, Revenue); Subscriber Portal (`/cie`) with tier-gated tabs (Market Pulse free, Securities/API Keys subscriber+, Signals pro+); Public marketing page (`/cie-intelligence`); and a landing page card under "For Platforms & Developers". Partner Programme: `cie_partners` table, admin Partners tab, one-time API key reveal, revenue-share tracking in Revenue tab. Partner keys bypass `cie_subscriptions` — tier resolved from `cie_partners.tier`. Icon eTrade provisioned as first partner (Pro tier, 60%/40% Cellion/partner revenue share). **Price Data Alerts (Task #109):** Admin Cockpit shows an amber banner above the tabs when no price data has ever been committed or when the most recent committed ingestion is ≥3 calendar days old. Banner includes "Go to Price Upload" button that switches to the prices tab. The 18:30 WAT scheduler also emails all admin users: Alert 1 ("missing_today") fires when today's securities are missing price data; Alert 2 ("stale") fires when the most recent committed ingestion is ≥3 days old. New `cieMarketContext` table stores daily ASI close, ASI change %, Brent crude, NGN/USD, CBN MPR, gainers/losers count, and analyst notes. Admin Price Upload tab redesigned: single Daily Upload card with drag-and-drop, Market Context input panel, colour-coded preview table (green/red close vs open), post-confirm "What Changed" panel (threshold crossings), and header buttons for Alpha Intel Report download, Run Score Engine, and Regenerate AI Commentary. -   **Public KYB API:** REST API at `/api/v1/kyb/*` exposing CAC registry lookups to third parties. Requires `verify:business` API key scope and deducts `kyb` credits (₦5,000/lookup). Three endpoints: `POST /api/v1/kyb/lookup` (RC number → company data + directors), `GET /api/v1/kyb/lookups` (paginated history), `GET /api/v1/kyb/lookups/:reference`. Results stored in `kyb_lookups` table. `kyb` credit type added to `PRICING_TIERS` in `kycBillingService.ts`. `verify:business` scope added to `ALLOWED_PERMISSIONS` for API key creation.
